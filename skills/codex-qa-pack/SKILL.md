# Codex QA Pack

Use this pack when test quality and release confidence are central.

## Focus Areas

- Test strategy by risk profile
- Regression prevention and coverage gaps
- E2E reliability and flaky test reduction
- Release gates and verification scripts

## Playbook

1. Align with `codex-workflows` selected workflow.
2. Define test scope and risk-based priorities.
3. Implement or run quality gates.
4. Report failures, gaps, and release impact.
