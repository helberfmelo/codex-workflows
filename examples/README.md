# End-to-End Examples

These examples show complete execution flows using explicit activation:

- `Use codex-workflows in /orchestrate ...`

Each example includes:

- project objective and constraints;
- prompt sequence;
- expected deliverables;
- stack validation commands.

## Example Catalog

1. `examples/node-auth-api/README.md`
Node + TypeScript API with auth, RBAC, tests, and CI quality gates.

2. `examples/python-fastapi-orders/README.md`
FastAPI service with async persistence, auth, contract tests, and deployment checks.

3. `examples/rust-events-cli/README.md`
Rust CLI/event processor with parsing, resilience, benchmarking, and release hardening.

4. `examples/projects/README.md`
Runnable fixture projects used by CI matrix to execute Node/Python/Rust stack checks.

5. `examples/real-world/README.md`
Larger blueprint scenarios for multi-week delivery programs.

6. `examples/quick-wins/README.md`
Profile-based quick wins for first-session execution.
