# /ui-ux-pro-max - Codex-Native Interface Direction

$ARGUMENTS

---

## Objective

Design and deliver a premium interface direction with implementation-ready guidance.

Use this workflow for:

- new product surfaces;
- redesign initiatives;
- UX quality upgrades requiring stronger visual identity.

---

## Design Principles

1. Intentional visual identity:
- avoid generic template look;
- establish clear typographic and color system.
2. System-level consistency:
- define reusable tokens/components;
- define spacing and hierarchy rhythm.
3. Functional clarity:
- optimize user flow before polish;
- remove interaction ambiguity.

---

## Design Sprint Protocol

### Phase 1: UX Framing

- define user jobs and success moments;
- map critical paths and friction points.

### Phase 2: Visual Direction

- propose at least 2 distinct visual directions;
- include typography, palette, and layout character.

### Phase 3: Selected Direction Expansion

- define tokens:
  - type scale
  - colors
  - spacing
  - radius
  - motion timing
- define component behavior states.

### Phase 4: Build Handoff

- map design decisions to code-level tasks;
- include responsive behavior and accessibility checks.

---

## Accessibility and Performance Gate

Must include:

- color contrast validation;
- keyboard/focus navigation behavior;
- reduced-motion fallback;
- lightweight rendering considerations.

Before closing:

- at least 2 design directions explored;
- selected direction includes token-level guidance;
- accessibility and responsiveness are explicit;
- handoff tasks are implementation-ready.
