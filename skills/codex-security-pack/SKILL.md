# Codex Security Pack

Use this pack when security risk is material to the request.

## Focus Areas

- Authentication and authorization safety
- Threat modeling and abuse cases
- Vulnerability scanning and remediation
- Secure deployment and secret handling

## Playbook

1. Align with `codex-workflows` selected workflow.
2. Map attack surface and trust boundaries.
3. Apply mitigations with verification steps.
4. Report residual risk and follow-up actions.
