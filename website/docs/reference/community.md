# Community

Use these channels to collaborate on `codex-workflows`:

- Issues:
  - Bug report template: `.github/ISSUE_TEMPLATE/bug_report.yml`
  - Feature request template: `.github/ISSUE_TEMPLATE/feature_request.yml`
- Pull requests:
  - PR template: `.github/PULL_REQUEST_TEMPLATE.md`
- Contributor guide:
  - `CONTRIBUTING.md`

## Recommended flow

1. Open an issue with reproducible context.
2. Align scope before implementation.
3. Submit PR with validations and docs updates.
4. Keep changes small and traceable.
