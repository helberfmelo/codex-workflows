# 社区

`codex-workflows` 协作渠道：

- Issues：
  - Bug 模板：`.github/ISSUE_TEMPLATE/bug_report.yml`
  - 功能请求模板：`.github/ISSUE_TEMPLATE/feature_request.yml`
- Pull Requests：
  - PR 模板：`.github/PULL_REQUEST_TEMPLATE.md`
- 贡献指南：
  - `CONTRIBUTING.md`

## 推荐流程

1. 先提交可复现上下文的 issue。
2. 实施前先对齐范围。
3. 提交 PR 时附上验证和文档更新。
4. 保持改动小且可追踪。
