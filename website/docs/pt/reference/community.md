# Comunidade

Use estes canais para colaborar no `codex-workflows`:

- Issues:
  - Template de bug: `.github/ISSUE_TEMPLATE/bug_report.yml`
  - Template de feature: `.github/ISSUE_TEMPLATE/feature_request.yml`
- Pull requests:
  - Template de PR: `.github/PULL_REQUEST_TEMPLATE.md`
- Guia de contribuicao:
  - `CONTRIBUTING.md`

## Fluxo recomendado

1. Abra issue com contexto reproduzivel.
2. Alinhe o escopo antes de implementar.
3. Envie PR com validacoes e atualizacao de docs.
4. Mantenha mudancas pequenas e rastreaveis.
