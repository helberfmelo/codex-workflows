# Communaute

Canaux de collaboration pour `codex-workflows`:

- Issues:
  - Modele bug: `.github/ISSUE_TEMPLATE/bug_report.yml`
  - Modele feature: `.github/ISSUE_TEMPLATE/feature_request.yml`
- Pull requests:
  - Modele PR: `.github/PULL_REQUEST_TEMPLATE.md`
- Guide contribution:
  - `CONTRIBUTING.md`

## Flux recommande

1. Ouvrir une issue avec contexte reproductible.
2. Aligner le scope avant implementation.
3. Soumettre PR avec validations et mise a jour docs.
4. Garder changements petits et tracables.
