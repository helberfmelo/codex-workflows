# Orchestration Phase Gates

Use this for complex tasks.

## Phase 1: Discovery

- Confirm objective and constraints.
- List affected domains.
- Decide if planning artifact is required.

## Phase 2: Planning

- Produce an execution plan with milestones.
- Define validations and rollback strategy.
- Stop for user approval before broad implementation.

## Phase 3: Implementation

- Execute by domain in clear steps.
- Keep commits or change chunks scoped.
- Track assumptions explicitly.

## Phase 4: Verification

- Run relevant tests and static checks.
- Validate security and performance risks when applicable.
- Report pass/fail evidence.

## Phase 5: Synthesis

- Summarize outcomes by domain.
- List unresolved risks.
- Provide next action options.
