# Comunidad

Canales para colaborar en `codex-workflows`:

- Issues:
  - Plantilla de bug: `.github/ISSUE_TEMPLATE/bug_report.yml`
  - Plantilla de feature: `.github/ISSUE_TEMPLATE/feature_request.yml`
- Pull requests:
  - Plantilla PR: `.github/PULL_REQUEST_TEMPLATE.md`
- Guia de contribucion:
  - `CONTRIBUTING.md`

## Flujo recomendado

1. Abrir issue con contexto reproducible.
2. Alinear alcance antes de implementar.
3. Enviar PR con validaciones y actualizacion de docs.
4. Mantener cambios pequenos y trazables.
